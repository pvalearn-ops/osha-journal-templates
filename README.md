# 危險性機械及設備 — 線上會談紀錄範本庫

供 Chrome 擴充功能「危險性機械及設備快速填入」遠端取用的會談紀錄 DOCX 範本。

擴充功能抓 `index.json` → 依案件的機械/設備種類與檢查種類挑範本 → 下載 `templates/<表單編號>.docx`
→ 在瀏覽器記憶體內把 `{{錨點ID}}` 換成案件資料 → 多份合併成一個檔給使用者。

## 目錄
```
index.json          範本清單＋每份的錨點登錄表
錨點對照表.md        每份表單有哪些錨點、各在哪一句話裡（校對用）
templates/*.docx    範本本體，檔名＝表單編號
```

## 錨點

語法是 `{{ID}}`，ID 是英數代號，**不是中文欄位名**。同一個欄位在任何表單都是同一個 ID。

錨點一定落在單一 run 裡，純字串取代即可，不必解析段落。

**同一份表單裡同一個欄位出現多次**（熔接、加熱爐等分次檢查的表），第 2 次起在 ID 後面加次別數字：
`CKY` / `CKY2` / `CKY3` 分別是第 1、2、3 次檢查的年。次別是從表單原文的「第 N 次」判定的，
不是按出現順序猜的。

### 代碼對照

**機械／設備種類 `ecCode`**（設備編號第 3 碼）
`E` 營建用升降機　`F` 固定式起重機　`G` 吊籠　`L` 營建用提升機　`M` 移動式起重機
`D` 人字臂起重桿　`B` 鍋爐　`P` 第一種壓力容器　`S` 高壓氣體特定設備　`H` 高壓氣體容器

**檢查種類 `ckCode`**
`0` 使用　`C` 竣工　`F` 定期　`L` 既有　`M` 變更　`R` 重新　`U` 構造　`W` 熔接

## index.json 欄位

| 欄位 | 說明 |
|---|---|
| `fields` | 錨點 ID 字典（ID、中文、RMEMS 來源） |
| `templates[].code` | 表單編號，取自文件最後一列「表單編號」 |
| `templates[].file` | `templates/` 下的檔名 |
| `templates[].rev` | 表單版次（民國年.月） |
| `templates[].name` | 表單名稱（已去掉單位全銜） |
| `templates[].source` | 原始中文檔名 |
| `templates[].ecCodes` / `ecNames` | 機械或設備種類代碼，可多值 |
| `templates[].ckCodes` / `ckNames` | 檢查種類代碼，可多值 |
| `templates[].ecType` | `A`＝設備、`B`＝機械 |
| `templates[].placeholders` | 這份範本含有的錨點 ID |
| `templates[].slots` | **錨點登錄表**：每個錨點的 `id` / `field`（中文）/ `round`（第幾次）/ `ctx`（所在句子） |
| `templates[].sha256` / `size` | 校驗用，快取比對就看這個 |

## 維護須知

- 範本改完請重跑產生腳本更新 `index.json` 的 `sha256` 與 `slots`，否則擴充功能的快取不會換新。
- 錨點必須是**單一 run**。在 Word 裡手動打 `{{...}}` 有可能被拆成多個 run，
  建議複製貼上既有的錨點再改 ID，存檔後用產生腳本驗一次。
- 表單最後一列的「表單編號」是識別依據，不要動。
- `W3-62-26A` 有兩份同編號的表（`W3-62-26A.docx` 與 `W3-62-26A-2.docx`），內容略有差異，待確認。
- `W3-02-02C`、`W3-02-06C` 的檢查員簽章列原本就沒有日期欄，所以沒有 `CKY/CKM/CKD` 錨點。
